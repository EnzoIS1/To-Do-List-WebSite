L'application n'a pas démarré

Ce projet n'est pas une page HTML autonome : il doit être compilé. L'ouvrir avec Live Server, ou en double-cliquant sur index.html, ne peut pas fonctionner — le navigateur ne sait pas lire les fichiers .jsx.

Dans un terminal, à la racine du projet :

npm install
npm run dev

Puis ouvre l'adresse que Vite affiche — elle se termine par /To-Do-List-WebSite/, pas par la racine du serveur.
